# Integrasi Kamera
Target pengujian pertama: Canon EOS 3000D.
Yang sudah ada: enumerasi Windows Plug-and-Play melalui Get-PnpDevice.
Belum ada: Canon EDSDK/PTP provider, shutter, image download, camera settings, Live View.
Jangan anggap enumerasi USB sebagai bukti tethering berfungsi. SDK Canon proprietary tidak disertakan; dapatkan sendiri dari Canon berdasarkan persyaratan regional yang berlaku.
